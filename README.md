## 👋 What's inside

A one-page "get to know me" site, built from scratch with plain HTML, CSS and JavaScript. No frameworks, no templates.

| | Section | What it does |
|---|---|---|
| 💁‍♀️ | **Get to Know Me** | The cosmetologist-to-developer story: from fixing bad bangs to fixing bad bugs |
| 🧰 | **My Skills** | A table of technical and transferable skills |
| 🎲 | **Fun Facts** | A JavaScript rotator that cycles through a new fact (and the occasional pet photo) every 7 seconds |
| 🛠️ | **Currently Working On** | What I'm learning right now |
| 💌 | **Get In Touch** | A contact form with required-field validation |

## ✨ Things I practiced building it

🎨 **Flexbox layouts:** a main column plus a sidebar, arranged with `flex-direction` and `row-reverse`<br>
🌈 **A custom color palette:** soft pinks, plums, indigo and teal, with translucent card backgrounds<br>
⚙️ **DOM manipulation:** the fun-fact rotator uses `setInterval`, a counter that loops back to the start, and `innerHTML` to swap in text and images<br>
♿ **Accessibility basics:** descriptive `alt` text on every image and labeled form fields

## ▶️ Run it locally

No build step needed:

```bash
git clone https://github.com/BrookeFloyd10/BrookeInCode.github.io.git
cd BrookeInCode.github.io
open index.html   # or just double-click it
```
